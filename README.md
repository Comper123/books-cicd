
# Books CI/CD

Учебный проект для поиска книг по автору.

## Запуск программы

```bash
python app.py books.json.example --author "пушкин"
```

## Запуск справки

```
python app.py --help
```

## Запуск тестов

```
python -m unittest discover -s tests -v
```

`Документация проверена в отдельной ветке.`
